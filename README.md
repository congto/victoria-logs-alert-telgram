# victoria-logs-alert-telgram
Victorialogs - vmalert - alertmanager - telegram

Các bước thực hiện


Tải repo

```
git clone https://github.com/congto/victoria-logs-alert-telgram.git
cd victoria-logs-alert-telgram/
```

Sửa file 


Chạy container 

```
docker compose up -d --build
```

Kiểm tra lại

```
docker ps
```
